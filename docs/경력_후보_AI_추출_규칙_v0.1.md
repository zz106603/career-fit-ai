# 경력 후보 AI 추출 규칙 v0.1

## 입력과 결과

PDF에서 저장한 페이지별 텍스트만 AI 입력으로 사용한다. AI 결과는 확정 경력이 아니라
`PENDING_REVIEW` 후보이며, 사용자가 검토하기 전에는 검색·판정의 기준정보로 사용하지 않는다.

후보마다 문서 분석 ID, 페이지 번호, 원문 발췌를 저장한다. 서버는 발췌가 지정된 페이지
텍스트에 실제로 포함되는지 다시 검증하며, 하나라도 확인되지 않으면 해당 응답 전체를
업무 데이터로 저장하지 않는다.

## Provider와 비용

기본 Provider는 Fake다. `AI_PROVIDER=openai`와 API 키를 외부 환경에 명시한 경우에만
OpenAI Responses API를 호출한다. 자동 테스트와 CI에서는 실제 API를 호출하지 않는다.
실제 호출은 입력·출력 토큰 및 재시도 횟수에 따라 비용이 발생할 수 있다.

모델, timeout, 최대 출력 토큰은 외부 설정으로 관리한다. API 키, Prompt 원문, 문서
원문과 전체 응답은 일반 로그와 AI 호출 관측 테이블에 저장하지 않는다.

## 트랜잭션과 실패

페이지 조회 후 트랜잭션을 종료하고 AI 호출과 backoff를 수행한다. 검증된 후보와 Evidence,
문서 분석 성공 상태만 하나의 짧은 트랜잭션으로 저장한다. Provider 또는 검증 실패 시
후보를 부분 저장하지 않고 문서 분석과 비동기 작업에 실패 코드를 남긴다.
